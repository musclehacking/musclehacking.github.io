There are no independently copied marketing bands or section cards beyond these findings. No icon package is installed. Existing artwork, file icons and the unique calculator clipboard icon remain unchanged. Numeric widths, gaps and colours are consolidated only when they represent the same role, not merely because they share a value.

## Verification and release boundary

Discover every document from each fresh `dist/client` build, including 404 and confirmation. Every changed shared global/header pattern covers all documents. Use exact decoded-pixel comparisons at 390×844, 768×1024 and 1440×900, first proving an unchanged repeat matches. Include affected hover/focus, share feedback, menu, supplement filters and calculator prompt states. Preserve rendered text/meaningful whitespace, semantic attributes and discovery output separately.

The standard local gates are check, test, build and verify:dist; full E2E uses only `scripts/run-e2e-local.sh`, followed by agent accessibility. Existing legacy visual comparisons allow differences and masks, so they cannot establish this refactor's stricter zero-pixel requirement. Temporary acceptance tooling and captures must remain ignored and be removed/retained under the evidence policy.
